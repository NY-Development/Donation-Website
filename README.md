# 💜 Donation Web App — React + Tailwind + GSAP

A modern, secure, and fully responsive **donation web application** built using **React (Vite)**, **Tailwind CSS v4**, and **GSAP animations**.

Designed to help users **discover campaigns, donate securely, and track social etfund** — with a clean UI, smooth animations, and scalable architecture.

## ✨ Features

- ⚛️ **React + Vite** — Fast development & optimized builds  
- 🎨 **Tailwind CSS v4** — Utility-first responsive styling  
- 🎬 **GSAP Animations** — Smooth transitions & scroll effects  
- 🧭 **React Router** — Public & protected routes  
- 🔐 **Auth-ready Routing** — Secure route guards  
- 💳 **Donation Flow** — Validated forms & API integration  
- 🧩 **Reusable Components** — Clean, scalable UI system  
- 📱 **Fully Responsive** — Mobile, tablet & desktop ready  
- 🧠 **Onboarding Flow** — Guided user introduction with animations
